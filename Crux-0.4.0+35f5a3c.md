# Crux 0.4.0 (build 316)

This is the first update delivered through Crux itself. From now on, new builds arrive here; you won't need to download them from the shared folder.

## Fixed

- **Crux no longer quits after your Mac sleeps.** This happened when the Controls module was on.
- **The hub closes when you move away.** It could stay open if it had opened while the pointer was just beside the notch.
- **No more "shortcut has been run" notices** each time the hub opens with Focus on. Crux now only runs its Focus shortcut when a Focus turns on, or when you tap a Focus button.
- **Volume and brightness pop-ups go away on time,** and hovering near one no longer opens the hub.
- **The settings gear no longer covers Media's mute button.**

## Improved

- **Smoother open and close.** The hub drops out of the notch as a narrow column and spreads once it's below the menu bar, then folds back the same way.

Already on build 315? You have all of the above; installing this one confirms updates reach you.

Found something off? Settings ▸ General ▸ Copy Diagnostics, and send it along with what happened.
